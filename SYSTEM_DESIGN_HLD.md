### High-Level Design (HLD)

```
┌─────────────────────────────────────────────────────────────────┐
│                         Client Layer                             │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  React Components (Next.js)                              │   │
│  │  - Chat Interface (Resizable Panels)                     │   │
│  │  - Message List with Animations                         │   │
│  │  - User Sidebar                                         │   │
│  │  - Preferences & Settings                               │   │
│  └──────────────────────────────────────────────────────────┘   │
│                            ▼                                      │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  State Management (Zustand)                              │   │
│  │  - Selected User State                                   │   │
│  │  - User Preferences                                      │   │
│  └──────────────────────────────────────────────────────────┘   │
│                            ▼                                      │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  Data Fetching (TanStack React Query)                   │   │
│  │  - Message caching and synchronization                   │   │
│  │  - User list queries                                     │   │
│  └──────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Communication Layer                           │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  WebSocket (Pusher)                                      │   │
│  │  - Real-time message delivery                           │   │
│  │  - User presence updates                                │   │
│  │  - Event subscriptions                                  │   │
│  └──────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Backend Layer (Next.js)                      │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  API Routes (/api)                                       │   │
│  │  - Authentication handlers                               │   │
│  │  - Message operations                                    │   │
│  │  - File upload signing                                   │   │
│  └──────────────────────────────────────────────────────────┘   │
│                            ▼                                      │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  Server Actions                                          │   │
│  │  - Fetch messages from database                          │   │
│  │  - User queries                                          │   │
│  │  - Data persistence                                      │   │
│  └──────────────────────────────────────────────────────────┘   │
│                            ▼                                      │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  Authentication (Kinde)                                  │   │
│  │  - OAuth 2.0 flows                                       │   │
│  │  - Session management                                    │   │
│  │  - User identity verification                           │   │
│  └──────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────────┐
│                     Data & Storage Layer                        │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  Upstash Redis                                           │   │
│  │  - User profiles (hash: user:*)                          │   │
│  │  - Message history (hash: messages:*)                    │   │
│  │  - Session state                                         │   │
│  └──────────────────────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  Cloudinary                                              │   │
│  │  - Image storage and optimization                        │   │
│  │  - Media transformation                                  │   │
│  └──────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```
